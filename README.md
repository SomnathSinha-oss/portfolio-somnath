# Somnath Sinha — Portfolio Website ⚡

A modern, highly responsive, tech-focused personal portfolio website engineered for **Somnath Sinha (Full-Stack Web Developer & IoT Engineer)**. 

Built with **React.js**, **Tailwind CSS**, and **Framer Motion**, featuring a cyber/hacker dark theme with neon green (`#00FF66`) and neon red (`#FF0055`) accents, inspired by the structure, layout flow, and UI/UX patterns of modern engineering portfolios.
